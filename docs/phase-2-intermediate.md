# 📗 Phase 2 — Intermediate Application (Frameworks & Tools)

> **Goal:** Move from *knowing* to *doing*. Learn the frameworks and hands-on tools BAs use daily.
> **Est. time:** ~4 weeks · **Style:** mix — learn a concept, then produce an artifact.

---

## 🎯 Learning objectives
- Navigate the **BABOK** framework and its 6 knowledge areas.
- Model a business process with **BPMN**.
- Write **use cases** and read basic **UML** diagrams.
- Write high-quality **user stories** with **acceptance criteria** (Gherkin).
- Create **wireframes** in Figma.
- Read/design a simple **data model (ERD)** and write **basic SQL**.
- Work within **Agile/Scrum** using **Jira** and **Confluence**.
- Prioritize requirements (**MoSCoW**) and run a **gap analysis**.

---

## 📚 Lessons

### Lesson 1 — The BABOK Framework (the BA "bible")
- 6 knowledge areas: Business Analysis Planning & Monitoring, Elicitation & Collaboration, Requirements Life Cycle Management, Strategy Analysis, Requirements Analysis & Design Definition, Solution Evaluation.
- **Practice:** Match each area to a task you'd do on a real project.

### Lesson 2 — Business Process Modeling with BPMN ⭐
- Core symbols: events (circles), activities (rounded rectangles), gateways (diamonds), flows (arrows), swimlanes/pools (who does what).
- **As-Is vs To-Be** process maps.
- **Tool:** [draw.io / diagrams.net](https://app.diagrams.net) (free) or Lucidchart.
- **Practice:** Model the "customer submits an invoice for approval" process.

### Lesson 3 — Use Cases & UML Basics
- **Use case diagram** (actors + system functions) and **activity diagram** (flow of actions).
- Writing a **use case description** (actor, preconditions, main flow, alternate flows).
- **Practice:** Write a use case for "Accountant reconciles a bank statement."

### Lesson 4 — User Stories + Acceptance Criteria ⭐
- **INVEST** qualities of a good story (Independent, Negotiable, Valuable, Estimable, Small, Testable).
- **Acceptance criteria** with **Gherkin**: `Given <context>, When <action>, Then <result>`.
- Epics → Features → Stories.
- **Practice:** Write 1 epic + 3 stories + Gherkin criteria for an "expense claims" feature.

### Lesson 5 — Wireframing & Prototyping (Figma)
- Low- vs high-fidelity wireframes; why BAs sketch screens.
- **Tool:** [Figma](https://figma.com) (free tier).
- **Practice:** Wireframe an "invoice list + search + filter" screen.

### Lesson 6 — Data Fundamentals: ERD
- Entities, attributes, relationships (one-to-many, many-to-many), primary/foreign keys.
- **Practice:** Draw an ERD for Customer → Invoice → Invoice Line Item.

### Lesson 7 — SQL for Business Analysts
- `SELECT`, `WHERE`, `ORDER BY`, `JOIN`, `GROUP BY`, aggregate functions (`SUM`, `COUNT`).
- Why BAs need it: validate data, write report specs, answer stakeholder questions.
- **Tool:** [SQLBolt](https://sqlbolt.com) / [Mode SQL tutorial](https://mode.com/sql-tutorial).
- **Practice:** Write a query for "total invoice amount per customer this month."

### Lesson 8 — Agile & Scrum in Depth
- Roles (Product Owner, Scrum Master, Dev Team), artifacts (Product Backlog, Sprint Backlog, Increment), ceremonies (Sprint Planning, Daily Standup, Review, Retrospective).
- Where the BA adds value in each.
- **Practice:** Describe what you'd contribute in each ceremony.

### Lesson 9 — Tools: Jira & Confluence
- Jira: epics, stories, tasks, boards, workflows.
- Confluence: documentation, requirements pages, meeting notes.
- **Tool:** free Atlassian cloud trial.
- **Practice:** Create an epic with 3 stories on a Jira board.

### Lesson 10 — Prioritization & Gap Analysis
- **MoSCoW** (Must / Should / Could / Won't).
- **Gap analysis:** current state vs. desired state → the gap = the work.
- **Practice:** Do a MoSCoW on 6 features; write a mini gap analysis for a manual → automated reporting change.

## ✅ Phase 2 deliverables
- One **BPMN** As-Is + To-Be process pair.
- A **use case description** + activity diagram.
- An **epic with user stories + Gherkin** acceptance criteria.
- A **Figma wireframe** of one screen.
- An **ERD** + 3 working **SQL queries**.
- A **Jira board** screenshot with a small backlog.

## 🧪 Self-check before moving to Phase 3
- Can I model a process in BPMN without looking up every symbol?
- Can I write a testable user story with acceptance criteria?
- Can I write a `JOIN` + `GROUP BY` query?
- Can I explain the Scrum ceremonies and the BA's role in each?
