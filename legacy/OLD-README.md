# 🎓 Business Analysis — My Learning Roadmap

A personalized, step-by-step path from **ERP/accounting implementation** → **Business Analyst**.

> Built around your background: Information Systems degree + 1.5 years implementing **MISA accounting software** + direct customer work. We convert that experience into formal BA skills, frameworks, and a portfolio.

---

## 🚀 How to use this

1. **Open `roadmap.html`** in your browser → your interactive dashboard (checkboxes + progress bar, saved automatically).
2. **Read the docs** in order (in the `docs/` folder) as you reach each lesson.
3. **Do the exercises** — this course is a *mix of theory + hands-on*. Building beats reading.
4. **Track progress** in `docs/progress-tracker.md` (or use the HTML).
5. In our chat sessions, we go **one concept at a time**, ending each with a **micro-challenge**.
